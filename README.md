# Forecasting the energy consumption

## Overview

### Brief presentation of the project

This project aims to forecast the energy consumption of a residence located in the northeast region of Mexico using electricity consumption enriched with weather data. It is useful in order to better understand energy consumption patterns, anticipate the periods with the highest energy consumption and try to reduce their energy cost.

## Installation setup

### Prerequisites:
- Have [uv](https://docs.astral.sh/uv/getting-started/installation/) installed on your machine.

Install the project

```sh
uv sync
```
This creates a new virtual environment at `.venv`, install a project-specific python executable whose version is set in `.python-version`, and install the project dependencies declared in `uv.lock` (which is programatically generated by uv from `pyproject.toml`).

Run the demo webui from the repo root
